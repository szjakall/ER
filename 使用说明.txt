在 frontend 目录：

1. npm.cmd install
2. npm.cmd run mock      （终端 1，本地模拟后端，可选）
3. npm.cmd run dev       （终端 2）
4. 浏览器打开 http://localhost:5173

注意：Windows PowerShell 里必须写 npm.cmd，直接写 npm 会被脚本执行策略拦住。

画布操作不依赖后端回包。未启动 mock/FastAPI 时仍可画图，图形保持墨色、不显示红/橙外环。
等 B 的后端就绪后，停掉 mock、直接启动他的服务（同样监听 ws://localhost:8000/ws），前端不用改。

常用操作：
- 滚轮 / 空格拖拽平移，Ctrl+滚轮以指针为中心缩放，左下角可切画布比例（含 A4 纵向）。
- 选择页面比例会自动重排整张 ER 图：实体分层、联系居中、属性环绕、统一缩放；整次操作可 Ctrl+Z 撤销。
- 左侧「适配 / 重排 / 适应 / 撤销」分别是自动适配布局、重新排列、适应页面、撤销上次布局。
- 拖动画布与「问题诊断」/「属性检查器」的交界可拉伸面板，尺寸会记住。
- 选中图形后拖角上的控制点可改尺寸；拖动单个图形不会触发自动重排。
