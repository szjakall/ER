# ER 图实时规范校验（课题二）

学生画 ER 图时实时给出规范校验反馈。前端负责画布与交互，通过 WebSocket 把每次操作发给后端，
再把后端返回的 `violations` / `suggestions` 分级显示：画布上只在图形**外侧**标红环 / 橙环，
诊断面板列出具体规则，图形本身始终保持教材式的白底墨线。

## 目录结构

| 路径 | 负责 | 说明 |

后端（B）与规则/测试（C）的目录待补充。

## 快速开始（复现前端）

需要 Node.js 18+（本项目在 Node 24 上验证通过）。

```bash
git clone https://github.com/szjakall/ER.git
cd ER/frontend
npm install
```

然后开 **两个终端**：

```powershell
# 终端 1：本地模拟后端（ws://localhost:8000/ws），只为前端联调三色标注
npm.cmd run mock

# 终端 2：前端开发服务器
npm.cmd run dev        # 浏览器打开 http://localhost:5173
```

> - **Windows PowerShell 里必须写 `npm.cmd`**，直接写 `npm` 会被脚本执行策略拦住（running scripts is disabled）。
> - 不启动 mock 也能画图，只是所有元素保持**墨色**、不显示红 / 橙外环（没有校验结果）。
> - 等 B 的后端就绪后，停掉 mock、启动他的服务（同样监听 `ws://localhost:8000/ws`），**前端代码一行都不用改**。

## 前端功能

- **画布**：教材式黑白陈氏记法 —— 直角矩形 = 实体、椭圆 = 属性、菱形 = 联系，
  连线墨色、联系名写在菱形里。工具栏「实体 / 属性 / 联系 / 连线」**单击建一个，双击进入连续创建**（`Esc` 退出）。
- **属性**：选中实体或联系 → 右侧「**批量添加属性**」，一行一个（也支持逗号 / 空格分隔），一次全部添加。
  - `*属性名` = 主键（实线下划线）；`#属性名` = 部分键（虚线下划线）。
  - 属性会自动画成旁边的椭圆并**扇形散开**（互相不重叠），也可以**拖动**微调位置。
  - 每个属性可切换 **椭圆 / 多值（双椭圆）/ 派生（虚椭圆）**；弱实体（双矩形）与标识联系（双菱形）在「高级」里开关。
- **联系基数**：只写在「菱形联系 ↔ 实体」的连线上，**一条线一个符号**（`1` / `N` / `M`，三元联系用 `P`），
  位置靠近实体端。点选那条线，线上会弹出 `1 N M P` 选择器。实体连属性的线不写基数。
- **分级反馈**：`violations` → 🔴 图形外红环，`suggestions` → 🟠 橙环，通过 → 不在画布上额外标记（状态栏计「通过」），未检查 → 灰。「问题诊断」面板按规则列出并可点击定位。
- **本地几何规则 R20**：连线压到其它元素或属性椭圆时，该连线标红提示「请拖动元素或属性椭圆避开」。
- **页面比例**：画布左下可切 自由 / 16:9 / 4:3 / 3:2 / 1:1 / 黄金比例 / A4 横向 / A4 纵向。
  选择比例时按页面自动重排整张 ER 图（实体分层、联系居中、属性环绕、统一缩放并居中填充），整次操作可撤销。
- **智能布局**：左侧「适配 / 重排 / 适应 / 撤销」，或在比例菜单里「自动适配布局 / 重新排列 / 撤销布局」。
  布局只改 `position / size / attr_offsets / layout_scale / free_end`，不改实体、属性、联系、基数等业务数据；
  字号、描边、连线端点与基数标签共用同一个内容级缩放，最小正文 12px。拖动单个图形不会触发自动重排。
- **布局辅助**：8px 吸附、对齐参考线；「重排」会用图结构重新分层并消除重叠。
- **面板**：画布与「问题诊断」/「属性检查器」的交界可拖拽拉伸，尺寸记在 localStorage；双击分隔条复位。
- **示例图**：工具栏三个按钮 —— 学生选课（M:N）/ 三元联系（M:N:P）/ 弱实体（1:N，双线矩形 + 部分键）。
- **文件**：导入 / 导出 JSON、全量检查、撤销 / 重做 / 清空。

## 与后端联调

- 地址固定 `ws://localhost:8000/ws`，UTF-8 JSON，2 秒超时（超时忽略，不阻塞画布）。
- 前端发出：`element_added` / `element_modified` / `element_deleted` / `connection_added` / `connection_modified` / `batch_check`。
- 前端接收：`result` / `batch_result` / `error`。
- 字段细节见 `INTERFACE.md`。
