# ER 设计规则清单（32 条）

> 本文件定义系统所有校验规则。每条规则包含：编号、名称、级别、检查对象、判断条件、提示语、实现方式、实现批次。
>
> - **级别**：error = 刚性错误（🔴 标红），warning = 启发建议（🟠 标橙）
> - **实现方式**：规则引擎 = 纯 Python 判断；LLM = 需要大模型语义理解
> - **批次**：第1批 = MVP 优先（1-2周）；第2批 = 扩展（3-4周）；第3批 = LLM 增强（6-7月）

---

## 一、实体规则（8 条）

| 编号 | 规则名 | 级别 | 判断条件 | 提示语 | 实现 | 批次 |
|---|---|---|---|---|---|---|
| R01 | 实体必须有名称 | error | name 为空或纯空格 | 存在未命名的实体 | 规则引擎 | 第1批 |
| R02 | 实体名必须唯一 | error | 多个实体 name 相同 | 实体名「{name}」重复出现 N 次 | 规则引擎 | 第1批 |
| R03 | 非弱实体必须有主键 | error | attrs 中没有 is_primary_key=true | 实体「{name}」缺少主键属性 | 规则引擎 | 第1批 |
| R04 | 非弱实体至少有一个属性 | error | attrs 为空列表 | 实体「{name}」没有任何属性 | 规则引擎 | 第1批 |
| R05 | 弱实体必须有部分键/鉴别器 | error | is_weak=true 但无 is_partial_key=true | 弱实体「{name}」缺少部分键 | 规则引擎 | 第2批 |
| R06 | 主键不能是多值属性 | error | is_primary_key=true 且 is_multi_valued=true | 主键「{name}」不能是多值属性 | 规则引擎 | 第2批 |
| R07 | 主键不能是派生属性 | error | is_primary_key=true 且 is_derived=true | 主键「{name}」不能是派生属性 | 规则引擎 | 第2批 |
| R08 | 孤立实体检测 | warning | 实体未参与任何联系 | 实体「{name}」可能是孤立实体 | 规则引擎 | 第2批 |

## 二、属性规则（7 条）

| 编号 | 规则名 | 级别 | 判断条件 | 提示语 | 实现 | 批次 |
|---|---|---|---|---|---|---|
| R09 | 属性必须有名称 | error | name 为空 | 有属性缺少名称 | 规则引擎 | 第1批 |
| R10 | 同实体内属性名唯一 | error | 同一实体存在同名属性 | 属性「{name}」重复 | 规则引擎 | 第1批 |
| R11 | 主键属性不允许为空 | error | is_primary_key=true 且 is_nullable=true | 主键「{name}」不允许为空 | 规则引擎 | 第2批 |
| R12 | 复合属性必须有子属性 | warning | is_composite=true 但 sub_attributes 为空 | 复合属性「{name}」未定义子属性 | 规则引擎 | 第2批 |
| R13 | 属性名不应与实体名相同 | warning | 属性 name 等于所属实体 name | 属性名与实体名相同 | 规则引擎 | 第2批 |
| R14 | 疑似派生属性未标记 | warning | 名称含"总计/平均/汇总"等但 is_derived 未设 | 属性「{name}」可能是派生属性 | 规则引擎 | 第3批 |
| R15 | 疑似多值属性未标记 | warning | 名称含"列表/集合/多个"等但 is_multi_valued 未设 | 属性「{name}」可能是多值属性 | 规则引擎 | 第3批 |

## 三、联系规则（8 条）

| 编号 | 规则名 | 级别 | 判断条件 | 提示语 | 实现 | 批次 |
|---|---|---|---|---|---|---|
| R16 | 联系必须有名称 | error | name 为空 | 存在未命名的联系 | 规则引擎 | 第1批 |
| R17 | 联系必须标注基数 | error | cardinality 为空 | 联系「{name}」缺少基数标注 | 规则引擎 | 第1批 |
| R18 | 联系基数必须是合法值 | error | cardinality 不在 {1:1, 1:N, M:N} 中 | 基数「{val}」不合法 | 规则引擎 | 第1批 |
| R19 | 联系两端必须连接存在的实体 | error | from_entity/to_entity 指向不存在的实体 | 联系指向了不存在的实体 | 规则引擎 | 第1批 |
| R20 | 联系名称唯一 | error | 多个联系 name 相同 | 联系名「{name}」重复 | 规则引擎 | 第2批 |
| R21 | 1:1 联系较少见 | warning | cardinality == "1:1" | 建议确认是否应为 1:N 或 M:N | 规则引擎 | 第2批 |
| R22 | 自环联系需确认 | warning | from_entity == to_entity | 请确认是否为递归联系 | 规则引擎 | 第2批 |
| R23 | M:N 联系建议有联系属性 | warning | cardinality=="M:N" 且 attributes 为空 | 建议补充联系属性 | 规则引擎 | 第2批 |

## 四、结构/全局规则（5 条）

| 编号 | 规则名 | 级别 | 判断条件 | 提示语 | 实现 | 批次 |
|---|---|---|---|---|---|---|
| R24 | ER 图至少有一个实体 | error | entities 为空 | ER 图中没有任何实体 | 规则引擎 | 第1批 |
| R25 | 多实体无联系 | warning | entities > 1 且 relationships 为空 | 存在 N 个实体但无联系 | 规则引擎 | 第2批 |
| R26 | 实体属性过多 | warning | attrs 数量 > 15 | 建议拆分或检查范式 | 规则引擎 | 第2批 |
| R27 | 主键属性过多 | warning | is_primary_key=true 的属性 > 3 | 建议检查是否可缩减 | 规则引擎 | 第2批 |
| R28 | 弱实体应依赖强实体 | error | 弱实体未通过联系关联到任何强实体 | 未通过联系依赖任何强实体 | 规则引擎 | 第2批 |

## 五、需求对齐规则（4 条）

| 编号 | 规则名 | 级别 | 判断条件 | 提示语 | 实现 | 批次 |
|---|---|---|---|---|---|---|
| R29 | 需求实体覆盖率 | warning | 需求文本提到的实体未出现在 ER 图中 | 缺失实体：{names} | 规则引擎 | 第2批 |
| R30 | 需求联系覆盖率 | warning | 需求文本提到的联系未出现在 ER 图中 | 缺失联系：{names} | 规则引擎 | 第2批 |
| R31 | 需求属性覆盖率 | warning | 需求文本提到的属性未出现在 ER 图中 | 缺失属性：{names} | 规则引擎 | 第2批 |
| R32 | 需求与设计命名一致性 | warning | 需求用词与 ER 图命名不一致（同义词表匹配） | 建议统一命名 | 规则引擎 | 第3批 |

```json
{

    {
      "id": "e1",
      "name": "学生",
      "is_weak": false,
      "attributes": [
        { "name": "学号", "is_primary_key": true, "is_partial_key": false,
          "is_composite": false, "is_multi_valued": false,
          "is_derived": false, "is_nullable": false, "sub_attributes": [] },
        { "name": "姓名", "is_primary_key": false, "is_partial_key": false,
          "is_composite": false, "is_multi_valued": false,
          "is_derived": false, "is_nullable": true, "sub_attributes": [] }
      ]
    }
  ],
  "relationships": [
    {
      "id": "r1", "name": "选课",
      "from_entity": "e1", "to_entity": "e2",
      "cardinality": "M:N",

}
```
